# SmartDrive 🚗📱

SmartDrive est une application web interactive développée dans le cadre d'un projet étudiant à l’école MDS Angers. Elle a pour objectif de sensibiliser les utilisateurs aux risques routiers et de les informer sur les bonnes pratiques de conduite.

## 🧠 Objectifs pédagogiques

- Sensibilisation aux dangers de la route (alcool, vitesse, téléphone, fatigue…)
- Mise en situation interactive via des quiz et animations
- Interface intuitive et responsive adaptée à tous les supports

## 🛠️ Technologies utilisées

- **HTML5 / CSS3**
- **JavaScript** (vanilla)
- **Figma** (pour la conception des maquettes)

## 📆 Contexte

Ce projet a été réalisé dans le cadre d’un module de développement web à l'école [MyDigitalSchool Angers](https://www.mydigitalschool.com/ecole-web/angers). L'objectif était de concevoir une entreprise du début jusqu'à la fin dans le thème de la mobilité et du transport.
